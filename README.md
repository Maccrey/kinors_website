# KINORA 홍보 웹 v4

이번 버전의 핵심 수정사항:
- 데스크톱 공통 콘텐츠 폭을 화면의 70%로 통일(좌우 각 15% 여백)
- 1240px 이하에서는 86%, 모바일에서는 92%로 반응형 전환
- 섹션별 임의 폭/좌우 패딩을 제거하고 `.shell` 기준선을 공통 사용
- 캐릭터 합성 이미지를 크게 확대하지 않고, `dog_full.png`, `cat_full.png`, `fluffy_full.png` 3개 독립 에셋으로 조합
- 강아지/고양이/지방이 모두 전체 몸이 보이도록 `object-fit: contain` 및 비클리핑 배치
- 언어별 JS 자동 축소 제거. 언어별 타이포그래피 변수만 사용해 시각적 크기를 일관화
- 일본어/중국어/한국어/영어/태국어/베트남어의 Hero 핵심 문구는 의미 단위별 한 줄 유지
- 기존 브라우저 언어 자동 감지 및 미지원 언어 → 영어 fallback 유지
- 기존 Splash MP4 유지

## v13 — 사전 가입 이메일을 Google Sheet에 저장
1. Google Sheets에서 새 스프레드시트를 만듭니다.
2. `확장 프로그램 > Apps Script`를 열고 `google_apps_script.gs` 내용을 붙여넣습니다.
3. `배포 > 새 배포 > 웹 앱`에서 실행 사용자 `나`, 액세스 권한 `모든 사용자`로 배포합니다.
4. 발급된 `/exec` URL을 `app.js`의 `KINORA_SHEET_ENDPOINT`에 붙여넣습니다.
5. 이후 모든 `사전 가입` 버튼이 이메일 입력 모달을 열고, 동의 후 제출하면 `PreRegistration` 시트에 저장됩니다.

저장 컬럼: `created_at`, `email`, `locale`, `source`, `consent`, `page`
중복 이메일은 새 행으로 추가하지 않습니다.
